## What it does

Report Scheduler AI learns when each stakeholder actually reads reports, then generates and delivers personalized report digests at the moment they're most useful — no more unread Monday PDF dumps.

## Key features

- **Smart timing** — delivery optimized per recipient's engagement patterns.
- **Personalized digests** — each person gets the KPIs relevant to their role.
- **Multi-channel delivery** — email, Slack, Teams, or embedded portal.
- **Data-freshness guard** — reports held if source data is stale (with [Data Quality Watchdog](https://ziontechgroup.com/data-quality-watchdog/)).
- **Engagement analytics** — know which reports are read, and prune the rest.

## Who it's for

Analytics and ops teams tired of building reports nobody opens.
